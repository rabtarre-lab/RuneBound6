# Settings plugin

Команда `/settings` открывает меню:
- скрыть ник
- сменить рост (0.4 – 1.3, только sponsor / sponsor+)
- разрешить / запретить садиться на тебя (GSit)
- показать / скрыть пинг в табе
- отключить PvP режим

Заголовок меню — неоновый жёлто-золотой (#FFE600), не жирный.

## Как получить .jar
1. Залей папку на GitHub.
2. Вкладка **Actions** → запусти **Build plugin** (или он стартует сам после push).
3. Открой завершённый запуск → **Artifacts** → скачай `Settings-plugin` → внутри `Settings.jar`.
4. Кинь `Settings.jar` в `plugins/` сервера (Paper 1.21+, Java 21).

Группы, которым доступен рост, меняются в `plugins/Settings/config.yml`.
